# Развёртывание на Selectel

Проверенное состояние на 14 октября 2026 года:

- Ubuntu 24.04, Python 3.12;
- приложение: `/opt/espbs`, виртуальное окружение: `/opt/espbs/.venv`;
- данные: `/var/lib/espbs`, владелец — системный пользователь `espbs`;
- systemd: `espbs.service`, автозапуск и перезапуск при ошибке;
- API слушает только `127.0.0.1:8765`;
- внешний адрес: `https://starosvetsky.ru/espbs/`;
- nginx завершает TLS и требует Basic Auth;
- текущий сайт в `/` не заменён.
- тестовая статическая витрина выгрузки: `https://starosvetsky.ru/parser-results/`.

Пароль панели хранится только в `/etc/nginx/.htpasswd-espbs`, не входит в Git.
Конфигурации находятся в `deploy/`. Перед применением новой версии обязательно
выполнить тесты, сделать резервную копию nginx-конфига и проверить `nginx -t`.

## Проверка сервиса

```bash
systemctl status espbs.service
journalctl -u espbs.service --since today
curl http://127.0.0.1:8765/api/jobs
nginx -t
```

После первого развёртывания через серверную панель выполнен реальный ограниченный
сбор Eltex 2/2. После перезапуска `espbs.service` задание, товары и события
остались доступны. Файлы SQLite принадлежат `espbs:espbs` и имеют режим `0600`.
Для этой партии подготовлен ZIP/XML, скачан на рабочий компьютер и проверен
независимой командой `python -m espbs verify`. Исходная серверная база сохранена.

## Обновление

Код сначала проверяется локально и отправляется в GitHub. На сервер передаются
только пакет `espbs` и `requirements-parser.txt`; `.git`, виртуальные окружения,
локальные базы и архивы не копируются. После обновления зависимостей:

```bash
/opt/espbs/.venv/bin/python -m pip install -r /opt/espbs/requirements-parser.txt
systemctl restart espbs.service
```

Развёртывание панели не означает готовность полного цикла архивов. Защита диска,
подтверждённое скачивание и отдельная очистка партий остаются этапом 4.

## Тестовая витрина

Каталог `catalog-demo/` — статическая страница для визуальной проверки конкретной
XML-выгрузки. `tools/build_catalog_page.py` сверяет размер, SHA-256, batch ID и
число записей с манифестом, затем создаёт безопасный `data.json`. На сервере
страница размещается отдельной папкой `/var/www/starosvetsky.ru/parser-results`;
корневые файлы портфолио при публикации не меняются.
