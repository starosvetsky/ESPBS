# Товары на сервере

Отдельная страница `inventory.html`, ссылка «Товары на сервере» в панели сбора.
После установки адрес: `https://starosvetsky.ru/espbs/inventory.html`.

Читает реальные записи `batches/*.sqlite3`, включая старые партии, которые не
мигрировали в общий каталог. Показывает число сохранённых записей и партий,
выбор партии, поиск по сохранённым полям без учёта регистра (включая кириллицу),
страницы по 30 записей и карточку товара. В карточке доступны основные поля,
характеристики, описание, ссылки на фотографии/документы и полный JSON.
Значения выводятся текстом, HTML источников не исполняется. Фото Olnisa не выводятся.
Фотографии представлены внешними ссылками: наличие ссылки не означает, что файл
изображения скачан на сервер.

Счётчик относится к записям, а не уникальным моделям: повторные сборы и партии
обогащения могут повторять товар. После подтверждённой очистки пустая партия
остаётся в списке с нулём записей. Сам экран ничего не удаляет и не запускает.
Обновление выполняется вручную. При продолжающемся сборе счётчик и страницы
могут изменяться; для перечитывания используйте «Обновить».

API:
- `GET /api/inventory/batches`: партии и суммарный `record_count`.
- `GET /api/inventory/products?batch=UUID&q=текст&after=CURSOR&limit=30`:
  `products`, `has_more`, `next_cursor`. Параметры необязательны; limit 1–100,
  q до 200 символов, курсор берётся из предыдущего ответа.

Записи читаются SQL-порциями, весь каталог в память не загружается. Поиск
сканирует JSON выбранных партий; на больших базах может потребоваться индекс
поиска. Отдельная глобальная дедупликация здесь не выполняется.
