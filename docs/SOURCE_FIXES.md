## Фотографии

В форме три режима: `store` — с исходного сайта; `official` — с официального;
`fallback` — исходный сайт имеет приоритет, официальный используется при отсутствии
исходных фото. Старый `none` остаётся совместимым для сохранённых заданий/API.
Режим наследуется отдельной партией обогащения, применяется перед сохранением и
отображается через происхождение изображений. Ошибка поиска производителя не
удаляет фото исходного сайта в режимах store/fallback.

Olnisa запрещён как источник фото во всех режимах. В store фото будут пустыми;
в fallback разрешены подтверждённые официальные фото. Подмена store на official
не выполняется. D-Link/QTECH/Eltex распознаются как официальные источники при
прямом сборе. Фото-placeholder QTECH no_photo не сохраняется. Разрешён проверенный
CDN NAG cdn.nag.shop; остальные междоменные изображения требуют настройки.
Сохраняются URL фотографий; бинарное скачивание вложений по-прежнему не реализовано.

## Ссылки и robots.txt

У входной ссылки удаляются utm_*, ysclid, yclid, gclid, fbclid, etext. Значимые
параметры, например page, остаются. Olnisa /manufacturers/eaton нормализуется с /.
Две склеенные ссылки отклоняются отдельной понятной ошибкой.

HTTPS-редиректы универсального клиента допускаются внутри исходного домена,
до пяти переходов, с повторной проверкой robots.txt, DNS/IP и TLS. Другой домен,
HTTP или непубличный IP запрещены. Редиректы robots.txt остаются закрытыми.

Заменена ошибочная комбинация urllib.robotparser и глобальных wildcard-запретов.
Теперь группы User-agent выбираются отдельно, поддерживаются * и конечный $,
приоритет определяется наиболее конкретным правилом, Allow выигрывает равенство.
В частности, Disallow: /? больше не превращается в запрет всего NAG.
Реальная проверка: каталог Aquarius на NAG разрешён и открывается.

QTECH /catalog/switches/ (категории, серии, карточки), NAG /catalog/ и /product/.
Также поддержана одиночная Product-микроразметка HTML. Произвольный h1 не считается
доказательством карточки. Модель на официальной карточке D-Link/QTECH берётся
из заголовка модели, варианты/суффиксы не удаляются.

Olnisa: при отсутствии разрешённой пагинации обходятся опубликованные подкатегории
.cat-menu внутри выбранной категории. Нельзя расширять выбранную категорию до
всего производителя. На DKC часть ссылок page-N содержит filter/sorting/price;
они запрещены robots.txt и не переписываются для обхода запрета. Выводится
source_warning; сравнение с expected_total сохраняет предупреждение о неполноте.
