# Упрощённый сбор — 15 октября 2026

В форме только HTTPS-ссылка и фотографии: официальные либо без фото.
Запуск одним нажатием, без предварительного пробного разбора и ручного лимита.
API принимает limit=null (или отсутствие limit): обход до исчерпания очереди.
Старые задания и их заданные лимиты не изменяются. Данные не удаляются.

## Исправление Olnisa

Причина 72 вместо 782: адаптер возвращал пустую очередь следующих страниц.
Ошибочное предположение о запрещённой query-пагинации скрывало реально
опубликованные разрешённые ссылки /manufacturers/eltex/page-2/ ... /page-11/.
Дополнительно исправлены допустимые URL карточек с заглавными буквами.
Живая проверка всех 11 страниц нашла ровно 782 уникальные ссылки.
Это проверка обнаружения, не утверждение о завершённом скачивании 782 карточек.
Заявленное число сохраняется в expected_total. При неполном безлимитном сборе
выводится предупреждение. Ошибка карточки сохраняет прогресс для продолжения.

## Фото и официальные данные

Фото Olnisa запрещены всегда. Другие магазинные фото также не извлекаются.
Режим none наследуется дочерним обогащением и удаляет изображения из результата,
включая вложенные original_record, official и JSON-LD. Бинарные фото не скачиваются.

Обогащение запускается автоматически отдельной партией. Справочник и настройки
сохранены в БД/API, но убраны из интерфейса. При отсутствии готовой ссылки идёт
поиск по опубликованным sitemap известного официального домена, с соблюдением
robots.txt. URL-кандидат не является доказательством соответствия: нужны точные
бренд + MPN либо существующий проверенный алиас. Суффиксы не отбрасываются.
Если официальная страница не публикует MPN, результат UNVERIFIED, не подмена.

Ограничение: автоматического определения официального домена произвольного
неизвестного бренда через внешний веб-поиск пока нет. Сейчас встроен Eltex;
ранее сохранённые официальные домены тоже используются. NO_MANUFACTURER означает
неподтверждённый домен, NOT_FOUND — отсутствие однозначной ссылки в его sitemap.
Интерфейс не требует от пользователя заполнять справочник ради обычного сбора.

## Реальные ограничения

Нет продуктового лимита в новом сценарии. Остаются диск (пауза с сохранением),
robots.txt, доступность сайта, защитный предел 100 000 страниц обхода, предел
XML одного архива 8 GiB. Автоматического разделения архивов пока нет.
Универсальное извлечение поддерживает JSON-LD и ранее сохранённые правила;
не каждый произвольный магазин будет распознан без разработки адаптера.

Синтетические тесты: 1000 товаров через окно очереди 500, nullable target,
пагинация/чужой раздел/query, наследование фото, несовпадение MPN при sitemap-поиске.
