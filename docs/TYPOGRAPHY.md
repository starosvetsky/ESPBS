# Шрифт проекта: Medeo

Основной шрифт интерфейсов — Medeo Sans. Для кода, журналов и технических
обозначений используется Medeo Mono. Веб-версии включают начертания 100–900
и курсив. Файлы содержат кириллицу, в том числе Ё/ё.

Источник: https://github.com/DNFDEVS/medeo-font. Точная ревизия записана
в `espbs/web/fonts/SOURCE.txt`. Шрифты скопированы без модификации, лицензия
SIL OFL 1.1 и авторы поставляются рядом с файлами.

## Где подключено

- Главная страница проекта: `styles.css`, локальный импорт из `espbs/web/fonts`.
- Панель сбора и каталог товаров: `espbs/web/app.css`, локальные `/fonts/`.
  API выдаёт только явно разрешённые CSS/WOFF2-файлы.
- Статическая витрина: `catalog-demo/styles.css`, собственная папка `fonts/`,
  чтобы витрину можно было скопировать на сервер независимо от API.
- Старый Tkinter-интерфейс: `espbs/typography.py`. На Windows TTF загружаются
  только в процесс приложения; системная установка не нужна. Сборщик EXE
  включает папку шрифтов. Сохранившийся старый GUI по-прежнему имеет прежние
  ограничения запуска; весь EXE в этом шаге не собирался. На других ОС для
  старого Tkinter понадобится установка Medeo в систему.

Google Fonts больше не используется. Новые экраны подключают тот же `fonts.css`
и используют `var(--sans)` / `var(--mono)`. При обновлении шрифтов синхронизируйте
веб-файлы и лицензию в `catalog-demo/fonts/` с `espbs/web/fonts/`.

## Продолжение из дома

После `git pull --ff-only origin main` файлы доступны вместе с кодом. Для
веб-интерфейса не требуется установка шрифта на компьютер. Обновление страницы
после перезапуска локального API подхватит Medeo. Если работает старый процесс
сервера, его нужно перезапустить для нового маршрута `/fonts/`.

GitHub Pages публикует шрифты вместе с главной страницей. Для ручного обновления
витрины копируйте всю `catalog-demo/`, включая `fonts/`. Для панели Selectel
нужно отдельное обновление приложения и перезапуск сервиса; в этом шаге сервер
не обновлялся.

Проверены 19 API-тестов, MIME-типы и сигнатуры WOFF2, запрет чтения посторонних
путей через маршрут шрифтов, наличие кириллицы во всех семи файлах шрифтов.
На Windows отдельным скрытым Tk-окном подтверждено фактическое использование
Medeo Sans для TkDefaultFont и Medeo Mono для TkFixedFont.
