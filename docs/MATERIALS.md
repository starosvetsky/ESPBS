# Полнота карточек — 20 октября 2026

Общий обработчик извлекает прямые ссылки PDF/DOC/XLS/ZIP/DWG/DXF/STEP из области
товара. Сохраняются исходная страница и отношение linked_from_product_page:
документ может относиться к серии, наличие ссылки не доказывает применимость
только к одной модели. Повторные URL объединяются; пробелы в ссылках кодируются.
Файлы по-прежнему не скачиваются, экспорт содержит ссылки.

Фото извлекаются из JSON-LD/микроразметки/OpenGraph, затем из галереи или img
с alt, совпадающим с названием. Запрет изображений Olnisa сохранён.
Определение официального источника использует справочник manufacturers,
с проверкой бренда при его наличии в карточке. Начальные домены: Eltex, D-Link,
QTECH, OSTEC. Существующие пользовательские настройки не перезаписываются.
Произвольный неизвестный домен не становится официальным автоматически.

Обогащение сохраняет исходные непустые поля, если официальный источник их
не содержит; объединяет характеристики и ссылки на документы. Старые карточки
официальных сайтов перечитываются в отдельную партию при запуске обогащения.
Карточки, уже собранные новым обработчиком с официального сайта, не порождают
пустой повторный этап. Идентичность проверяется по бренду и точному коду;
для Eltex допускается точное название модели в официальном заголовке с
сохранением способа подтверждения. Суффиксы моделей не отбрасываются.
Удаляется только дублирующее написание в скобках, например X-1 (X1).
Поиск в sitemap учитывает дефисы/подчёркивания и URL-кодирование. Это остаётся
ограниченным поиском, а не универсальной поисковой системой по всему интернету.

coverage в товаре содержит наличие фото, документов, характеристик и описания.
Счётчики задания показывают число заполненных карточек по каждому полю.
COMPLETED означает обработку очереди, не полноту/корректность всех карточек.
При отсутствующих полях ставится REVIEW; FILLED означает только наличие полей.
Старые партии не пересчитываются и не переписываются: панель сообщает, что
заполненность ранее не измерялась.
