# Подтверждение копии и очистка

Реализовано локально 15 октября 2026 года. На Selectel этот шаг ещё не установлен.

1. Завершить задание, подготовить ZIP/XML и скачать его на компьютер.
2. На компьютере с актуальным кодом ESPBS выполнить:

   ```shell
   python -m espbs verify downloaded.zip --receipt receipt.json
   ```

   Проверяются структура архива, XML, количество записей и контрольные суммы. Отчёт создаётся только после успешной проверки; существующий файл отчёта не перезаписывается.
3. В панели выбрать `receipt.json` и нажать «Подтвердить копию». Сервер сверяет ID партии, SHA-256 ZIP и XML и количество записей со своим проверенным архивом и сохранённой контрольной суммой партии.
4. Отдельно нажать «Очистить партию на сервере» и ввести полный ID задания. Удаляются товарные записи этой партии и её серверный ZIP. SQLite уплотняется. Метаданные партии, очередь URL, счётчики и журнал остаются для истории.

Подтверждение копии не удаляет данные. Отчёт — заявление владельца о проверке локального файла, а не удалённое доказательство наличия диска: его можно вручную подделать. Не подтверждать очистку, если архив не сохранён в надёжном месте. Сервер не получает локальный путь или содержимое архива.

Состояния хранения: VERIFIED — копия подтверждена; CLEANING — очистка началась; CLEANED — завершена. При ошибке в середине очистки исходный серверный набор может быть уже частично удалён; сохранённая локальная копия остаётся источником восстановления. Повторное явное подтверждение продолжает очистку. Автоматических повторов и автоматического удаления нет. Завершённую очистку можно подтвердить повторно без побочных действий.

Операции упаковки, скачивания и очистки используют общую блокировку партии. Если операция занята, повторите позже. Удаляются только записи известной БД и фиксированный ZIP в каталоге exports; пользователь не передаёт путь удаления. Архив после начала очистки нельзя создать заново из оставшихся метаданных.

API: `POST /api/jobs/ID/confirm-copy` принимает JSON-отчёт; `POST /api/jobs/ID/cleanup` принимает `{"confirmation":"полный ID"}`. POST требует `Content-Type: application/json`. Доступ извне по-прежнему должен защищаться HTTPS и аутентификацией reverse proxy.

Проверены синтетическими тестами: отсутствие подтверждения, чужая контрольная сумма, неверное согласие на очистку, изменённый серверный архив, очистка и её повтор, сбой удаления ZIP и продолжение. Весь набор: 38 тестов. Серверные данные пользователя не удалялись. Визуальная проверка новых элементов панели и проверка полного сценария на Selectel пока не выполнены.

Следующий шаг: проверить весь сценарий в браузере на отдельной тестовой партии, затем установить обновление на Selectel после проверки состояния сервера. Уплотнение больших SQLite требует временного места; при его нехватке очистка остаётся CLEANING для повторного запуска после освобождения места.
