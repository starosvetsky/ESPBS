# Распознавание разных сайтов

Обновление 17 октября 2026. Общий HTML-анализ работает на произвольных доменах
через существующий generic-адаптер. Отдельные проверенные адаптеры сохранены.
Регистрация производителя и изменение правил HTTP-доступа не требуются.

Поддерживаемые признаки:

- Product JSON-LD, включая mainEntity и полное имя типа schema.org;
- ItemList JSON-LD со ссылками на элементы;
- микроразметка Product: название, бренд, MPN, SKU, цена, валюта;
- повторяющиеся HTML-строки с ценами и ссылками, плитки товаров;
- таблицы с колонками артикула и наименования, даже без цен;
- пары характеристик в таблицах, definition lists и двухколоночных div-блоках;
- пагинация page/p/paged/page_number/PAGEN_N с сохранением фильтров.

Основная структурированная карточка имеет приоритет перед рекомендациями.
Product с URL другой карточки не превращает страницу категории в товар.
Меню, подвал, формы, рейтинги и явно обозначенные рекомендации исключаются из
эвристического анализа. Ссылки действий корзины, файлов и другого сайта не берутся.
Произвольный h1 не достаточен: HTML-карточка без schema должна иметь артикул/MPN
и цену или несколько пар свойств. Такой результат получает REVIEW.

Артикул продавца (`sku`) не подставляется в MPN. Бренд не выводится из домена.
Неустановленные поля остаются пустыми, причина видна в quality. Метод извлечения
сохраняется в provenance.recognition. Заголовок раздела не подменяет товар.

Ограничения: это расширение поддержки типов разметки, а не гарантия для каждого
сайта. Чистые JS-каталоги без товаров в исходном HTML, неоднозначные варианты и
необычные структуры требуют правил или адаптера. JavaScript не выполняется;
ограничения источника не обходятся. Общая эвристика не гарантирует полный каталог,
а неоднозначные строки может пропускать. Наличие следующей страницы определяется
по реальным ссылкам, адреса не угадываются. Фотографии и документы остаются в
существующем отдельном механизме; этот шаг расширяет распознавание товаров.

Реальная проверка OSTEC выполнена штатным HTTPS-клиентом с robots.txt:
раздел /catalog/kabelenesushchie-sistemy/kabelnye-lotki-lnmzt-lpmzt/bez-perforatsii/.
Найдены 25 ссылок и переход на вторую страницу. Пробный разбор первых трёх
карточек завершился без ошибок (can_start=true), по 11 групп атрибутов;
это не полный обход каталога. В первой карточке артикул извлечён
в SKU, бренд и MPN не придуманы. Отдельного условия на ostec.ru в коде нет.
Тесты используют синтетические таблицы, плитки и схемы на разных доменах,
включая отрицательные случаи: категории, новости, рекомендации и ссылки корзины.
Полный набор проверок: 86 тестов прошли. Проверка миллиона позиций не выполнялась.

Изменения локальные и в Git; развёртывание на Selectel отдельно.
