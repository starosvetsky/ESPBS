ENERGOSTOR PARSER v0.5

1. EDITABLE SOURCE POLICIES
Теперь галочки реально переключаются прямо в интерфейсе.

После изменения нажать:
СОХРАНИТЬ ПОЛИТИКУ

Настройки сохраняются в:
config\sources.json

При попытке впервые включить изображения для источника
программа показывает дополнительное подтверждение.

Пример Olnisa:
[ ] Изображения
[x] Документы
[ ] Описание
[ ] Цена
[x] Характеристики
[x] Производитель
[x] Категория

2. OLNISA PRODUCT DISCOVERY FIX

v0.4 ошибочно принимала страницы категорий за товары:
"Контакторы Eaton (1 020 товаров)" -> model 020

v0.5:
- страницы с H1 "(N товаров)" считаются категориями;
- категория обходится дальше;
- карточка принимается только при наличии явного
  "Артикул" / "Код товара" / "Модель";
- число товаров больше никогда не используется как SKU;
- loose manufacturer parsing из маркетинговых абзацев убран;
- manufacturer берётся из структурированного поля или URL бренда.

первый тест может занять заметно больше времени.
