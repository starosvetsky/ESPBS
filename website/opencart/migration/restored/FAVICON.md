# Фавикон

24.11.2026: существующая молния из lightning.svg на синем фоне #0b54a0.
Основной формат — SVG, запасной — PNG 32×32, Apple Touch — 180×180.
В корне сайта favicon.ico с размерами 16–256 для старых клиентов.
Файлы устанавливает restore-design.py, ссылки заданы в общей шапке.

Проверены HTTPS 200 и MIME всех четырёх файлов, декодирование PNG/ICO,
ссылки в HTML главной, страницы партнёров и вендоров. PNG проверен визуально.
