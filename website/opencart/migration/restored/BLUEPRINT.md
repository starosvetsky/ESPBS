# Чертёж шкафов в футере

24.11.2026. Ручное построение по референсу владельца, без трассировки,
растров, Canvas, видео, фильтров или сторонних библиотек.

## Файлы

- assets/footer-engineering.svg — самодостаточный статичный SVG 580×430.
- blueprint.twig — тот же SVG, включённый непосредственно в DOM футера.
- build-blueprint.py — воспроизводимое построение обеих копий. Координаты
  деталей редактируются здесь; после правки запустить скрипт.
- blueprint.css — изолированные стили и конечные CSS-анимации.
- blueprint.js — IntersectionObserver и однократный запуск.
- preview-blueprint.py — подготовка отдельного локального HTML-компонента.

Пример локального запуска:

    python preview-blueprint.py D:/Codex/ESPBS/blueprint-preview
    python -m http.server 8089 --bind 127.0.0.1 --directory D:/Codex/ESPBS/blueprint-preview

preview: index.html — анимация; static.html — без подключения скрипта;
reduced.html — имитация ответа matchMedia(matches=true) для проверки ветки JS.
Последняя не заменяет эмуляцию системной настройки браузера.

## Геометрия и движение

Общая изометрическая система обоих корпусов: оси (√3/2, −1/2),
(−√3/2, −1/2), (0, 1). Плоскости и детали строятся из этих базисов;
фронтальные модули лежат в одной плоскости с рамкой двери.
ID-группы разделяют направляющие, оба корпуса, панели, модули, вентиляцию,
индикаторы, размеры. Маркировок производителей и характеристик нет.

0–0.8s — направляющие; 0.5–2s — рёбра большого шкафа;
1.4–2.8s — его рамка и модули; 2–3.2s — малый шкаф;
2.8–4s — размеры и индикаторы. Только 18 рёбер анимируются по длине,
остальные группы проявляются прозрачностью. После 4.2s классы анимации
снимаются, таймер завершается. Повторного построения при прокрутке нет.

Статичный рисунок виден по умолчанию. Без JS, без IntersectionObserver и при
prefers-reduced-motion сразу показан готовый SVG. Изменение настройки motion
во время анимации тоже завершает построение. Размер контейнера постоянный.
