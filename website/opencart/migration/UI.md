## Что изменено

Главная переведена с отдельного полного HTML-документа на общие header/footer
OpenCart. Теперь поиск, меню, контакты, форма запроса и юридические ссылки
одинаковы на всех типах страниц. Новый футер содержит каталог, компанию,
контакты, реквизиты и правовую информацию. Неработающие ссылки на аккаунт,
корзину и оформление покупки в публичной навигации не используются.

Категории, страницы производителя и поиск используют `ui/listing.twig`:
104 раздела и подраздела, боковая навигация, сворачиваемые подразделы,
сортировка, пагинация и выбор количества товаров. Список — основной вид;
плитка включается кнопкой. Выбор сохраняется локально в браузере. При отсутствии
фото строка товара показывает небольшой нейтральный значок, без большой пустой
карточки. Главная страница каталога содержит 13 направлений с иллюстрациями.

В карточке товара добавлены название, производитель, копирование артикула,
количество для запроса, галерея, описание, характеристики и документы. При
отсутствии фотографии показывается содержательное описание позиции. Форма
запроса подставляет товар, артикул, количество и URL; существующий способ
отправки через почтовое приложение сохранён и указан посетителю.

Переработаны список брендов с поиском и алфавитом, вендоры, информационные и
юридические страницы, новости, статьи и HTML-карта сайта. Карта содержит только
действующие разделы. 404 и ранее удалённые страницы 410 получают фирменное
оформление с поиском и ссылками на каталог. Статусы 404/410 сохраняются.

Типографика — локальный Medeo Sans, начертания 400 и 500, обычный межбуквенный
интервал. Синий — #0b54a0; единая шкала отступов, полей, кнопок и состояний
фокуса. Проверены размеры 320, 390 и 1280 пикселей; мобильное меню и каталог
имеют самостоятельную компоновку. Поле количества, поиск, сведения о товаре
и контакты остаются доступными на узком экране.

## Бренды и старые ссылки

В исходном импорте было 203 записи производителей, в том числе 135 вариантов
с примесью характеристики «Диаметр, мм — …» и запись «Производитель: SIEMENS».
`ui-helpers.php` распознаёт только эти механические и подтверждаемые формы,
для которых уже существует точное основное название. В интерфейсе — 67 брендов;
136 прежних адресов перенаправляются 301 на основные страницы. Неподтверждённые
похожие названия не объединяются.

Товарные данные не переписываются. Чтение товаров и подсчёт результатов по
производителю используют одинаковый `IN` по исходным manufacturer_id группы.
Карточки показывают нормализованное название и ссылку на основной бренд.
База сохраняет все 55 359 товаров, их ID, артикулы и исходные manufacturer_id.
Из XML-карт убраны только URL подтверждённых вариантов с перенаправлением.

В старых информационных материалах исправляется регистр существующих внутренних
адресов. Ссылки на производителя, для которого нет старой страницы, ведут в
вендоры с заполненным поиском. Существующие внешние источники и документы
не заменяются. Повторяющийся старый рекламный хвост скрывается при отображении;
оригинальный текст в базе остаётся доступным.

## Установка

Исходники оформления находятся в соседнем каталоге `ui/`.

```sh
# Копировать из текущей ветки website в /opt/energostor-next/:
# install-ui.py, ui/, verify-ui.py, verify-ui-brands.php, verify-ui-search.py
python3 /opt/energostor-next/install-ui.py /opt/energostor-next
python3 /opt/energostor-next/verify-ui.py
php /opt/energostor-next/verify-ui-brands.php
python3 /opt/energostor-next/verify-ui-search.py
```

Установщик сначала подготавливает изменения, сохраняет заменяемые файлы вне
webroot в `ui-backups/<UTC>/`, проверяет PHP и затем заменяет файлы. Путь цели
жёстко ограничен `/opt/energostor-next`. Ни товарная база, ни парсер, ни заказы
не меняются. Повторный запуск поддерживается. При включённой проверке времён
файлов OPcache PHP-FPM не перезагружается: это предотвращает сброс активных
запросов. При отключённой проверке применяется штатный reload.

При установке с нуля порядок: тема → юридические страницы → редакционный
раздел → `install-ui.py`. Для ежедневных публикаций достаточно
`install-editorial.py`: общую оболочку он сохраняет. Для обновления только
юридических текстов использовать `install-legal.py … --content-only`.

Для отката восстановить затронутые файлы из нужного `ui-backups/<UTC>` по
`manifest.txt`; исходный каталог повторно не импортировать. После восстановления
очистить только компиляции Twig в `upload/system/storage/cache/template`, затем
проверить страницы. Общие данные и партии парсера не удалять.

## Проверки

Полный обход: 461 адрес — главная, все 104 категории, 203 исходных адреса
производителей с учётом 301, все 105 информационных страниц, каталог, список
брендов, вендоры, новости, карта сайта, три состояния поиска, 39 товарных страниц
и 404. Ошибок шаблонов и неизвестных внутренних ссылок нет. Ещё шесть адресов
удалённых разделов проверены отдельно на 410 и общую оболочку: всего 467
различных адресов. Это выборочная проверка товарных URL, а не HTTP-обход всех
55 359 карточек; единый шаблон применяется ко всем товарам.

Для объединённых брендов отдельно сверены счётчики интерфейса с SQL по исходным
ID: EKF — 2640, ЭРА — 273, IEK — 1914, Промрукав — 2829, Siemens — 282,
TDM ELECTRIC — 716, УралОмегаПласт — 85. Проверено полное и однократное покрытие
203 исходных записей в 67 группах; число товаров осталось 55 359.

Поиск учитывает бренд вместе с названием и артикулом. Слова запроса соединяются
условием «и»; дефис в названии бренда необязателен. Проверены D-Link и Dlink
(379 результатов), D-Link DGS (119), несовместимые бренд и модель (0), точный
артикул _265236 (1) и отсутствующий запрос (0). Числа в этих проверках привязаны
к снимку каталога на дату обновления и изменятся после следующего импорта.
Заголовки главной, поиска, карты сайта и страниц ошибок приведены к русскому
названию компании; стандартный заголовок OpenCart Your Store больше не выводится.

В браузере проверены главная, каталог, листинг и переключатель вида, товар и
подстановка запроса, бренды и поиск, вендоры, меню и футер. Финальные скриншоты
хранятся локально среди проверочных артефактов; в Git не включаются.
