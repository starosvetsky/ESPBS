# Перенос energostor.ru на OpenCart

На Selectel подготовлена витрина OpenCart 4.1.0.4. Файлы находятся в `/opt/energostor-next/upload`, база — `energostor_next`. Предпросмотр — `https://starosvetsky.ru/energostor-next/`, доступ через существующую учётную запись `preview`.

## Переключение DNS

1. В DNS-зоне задайте A-запись `energostor.ru` со значением `136.234.4.214`. Оставьте `www` CNAME на `energostor.ru` или назначьте ему тот же IP. Записи почты MX и TXT сохраняются.
2. На сервере таймер `energostor-next-https.timer` проверяет оба имени раз в десять минут. Когда DNS дойдёт до сервера, Certbot выпустит сертификат и включится перенаправление на `https://energostor.ru/`. Для немедленной проверки выполните `systemctl start energostor-next-https.service`. Результат виден в `journalctl -u energostor-next-https.service -n 30`.
3. Проверьте главную, `/catalog`, поиск, одну карточку с документами и загрузку `/sitemap.xml`. После этого отправьте `https://energostor.ru/sitemap.xml` в Google Search Console и Яндекс Вебмастер.

Для отката DNS верните A-запись на адрес прежнего хостинга `176.57.65.191`. Старая витрина остаётся доступной у прежнего провайдера до отключения его услуги.

## Что входит в сборку

Из каталога перенесены названия, артикулы, описания, разделы, бренды и характеристики. Изображения и документы подключены по исходным HTTPS-ссылкам. Корзина и оформление заказа закрыты. Запрос КП открывает заполненное письмо в почтовом приложении посетителя.

Основные старые URL обслуживаются средствами OpenCart. Для дублей настроены 301, для удалённых служебных страниц — 410. Sitemap содержит канонические адреса будущего домена. Поиск, служебные страницы и товарные записи без достаточных данных исключены из карты. Копия под паролем также отдаёт заголовок noindex.

Импорт — разовый снимок. `import-release.py` пересоздаёт данные витрины внутри транзакции и предназначен для отдельной базы сборки. Его нельзя запускать поверх рабочей базы с заказами и редакторскими правками. `extract-legacy.php` подготавливает тексты для импорта, `install-theme.py` переносит фирменное оформление и каталожные шаблоны. Публичный корень не включает SQL, исходные снимки и файлы маршрутов.

22.11.2026 домен подключён, сертификат Let's Encrypt выпущен для `energostor.ru` и `www.energostor.ru`, пробное продление успешно. Полные страницы политики, согласия, cookies, реквизитов и условий работы опубликованы через `install-legal.py`; после повторной установки темы этот шаг нужно повторить. Схема обработки, источники реквизитов и оставшиеся организационные действия описаны в [LEGAL-OPERATIONS.md](LEGAL-OPERATIONS.md).

22–23.11.2026 все типы страниц переведены на общее оформление. Установка, поведение каталога, нормализация представления брендов и результаты проверок описаны в [UI.md](UI.md). При полной переустановке `install-ui.py` запускается последним. Для дальнейшей правки юридических текстов без изменения оформления есть `install-legal.py /opt/energostor-next --content-only`.
