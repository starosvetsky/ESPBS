- Nginx: snippet `/etc/nginx/snippets/energostor-catalog.conf`, подключён в существующий HTTPS server. Прокси `/energostor/api/catalog/` удаляет префикс; клиент обращается к `api/meta`, `api/products`, `api/products/<id>`.
- Существующий парсер `espbs` и его защищённый `/espbs/` не менялись.
- Страницы `catalog/`, `brands/`; общая шапка и новое светлое меню используют `assets/js/navigation.js`. Меню DeepSeek не подключено. Старый адрес `catalog/d-link/` перенаправляет на общий каталог с фильтром D-Link.

## Обновление

`energostor-catalog-refresh.timer` запускает сборку раз в 30 минут. Успешная сборка атомарно заменяет только производную базу, затем перезапускает API для сброса кеша и открытых соединений. При ошибке существующая база остаётся доступной. Лимит базы 1536 МБ, сборка поточная. Ручной запуск: `systemctl start energostor-catalog-refresh.service`.

Логи: `journalctl -u energostor-catalog-refresh -n 40 --no-pager`. Состояние: `systemctl status energostor-catalog energostor-catalog-refresh.timer`. Пересборка полного набора заняла около 36 секунд.

## Исправления после проверки

Дедупликация сохраняет точный MPN: не удаляет знаки, пробелы внутри или регистр артикула. Повторные снимки одной записи без артикула обрабатываются безопасно; разные записи без MPN не объединяются по названию. Пропущенные медиа и характеристики переносятся из старого снимка независимо от порядка партий. Убрано ограничение на 40 характеристик и короткое обрезание их значений. Добавлены защита от перезаписи источника и fsync временной базы перед заменой. Исправлены счётчики, очистка HTML и рекламных контактов. Дополнены осторожные правила для категорий без исходного пути.
