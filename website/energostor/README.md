# ЭНЕРГОСТОР — главная страница

Статическая страница, собранная из Tilda-экспорта (`page126582966.html`).
Без сборки, без npm, без внешних зависимостей: чистый HTML + CSS + JS.

```
energostor/
├── index.html          — вся страница
├── send.php            — обработчик формы (опционально)
├── robots.txt
└── assets/
    ├── css/style.css   — стили, дизайн-токены сверху (--blue, --bg, шрифт)
    ├── js/main.js      — меню, мегаменю, модалка, форма, появление блоков
    └── img/            — картинки в webp, логотипы в svg
```

## Локальный просмотр

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory D:\Codex\starosvetsky\energostor
```

Открыть http://127.0.0.1:4173 — или просто двойным кликом по `index.html`
(в этом случае не работает только отправка формы).

## Что где менять

| Что | Где |
|---|---|
| Цвета, шрифт, ширина контейнера | `assets/css/style.css`, блок `:root` |
| Тексты, карточки, ссылки | `index.html` (секции помечены комментариями) |
| Картинки | `assets/img/`, ссылка в `index.html` |
| Заголовки модального окна и тема письма | `assets/js/main.js`, объект `MODAL_TEXTS` |
| Куда уходят заявки | `send.php`, константы `MAIL_TO` / `MAIL_FROM` |

Шрифт: сейчас системный `Arial` — как в исходной вёрстке Tilda.
Хочется Inter — правь `--font` в `:root` и подключай шрифт одним `<link>`.

## Форма

Кнопки «Получить КП и сроки», «Обратная связь», «Передать ссылку на спецификацию»,
а также блок консультации открывают одно модальное окно с разными заголовками.

Отправка:

1. `fetch` POST на `send.php` (рядом с `index.html`), ответ — JSON `{"ok": true}`.
2. Если `send.php` недоступен (нет PHP, открыт через `file://`), пользователь видит
   сообщение с телефоном и почтой — заявка не теряется молча.

`send.php` требует PHP 7.4+ и работающего `mail()`. Если почта на сервере не
настроена — поменяй отправку на SMTP (PHPMailer) или на внешний сервис,
это одно место в файле.

Альтернатива без PHP: убрать `action="send.php"` и подставить endpoint
Formspree / Getform / своего бэкенда — JS уже отправляет `FormData`.

## Размещение

Это локальная главная страница, а не полный перенос сайта. Для отправки заявок
нужны PHP с расширением mbstring и настроенная серверная почта. Обычный статический
сервер Python форму не обрабатывает. Успех показывается только после JSON `{"ok": true}`;
даже он означает принятие письма функцией mail(), а не доставку в почтовый ящик.

Не направляйте fallback-прокси на https://energostor.ru после переключения этого
домена на новый сервер: запрос может вернуться на тот же сервер и зациклиться.
Для поэтапного переноса нужен отдельно проверенный адрес старого origin либо
полный экспорт внутренних страниц. Готовая конфигурация хостинга пока не подготовлена.

Кнопка спецификации принимает ссылку в сообщении. Вложения не реализованы.
Перед публикацией нужны проверка почты, защита формы от массовых отправок,
проверка ссылок и сверка контента с исходной выгрузкой Tilda.

## Что изменено относительно Tilda

Собрано по исходной странице, но с исправлениями:

- **Шапка.** В Tilda пункты меню шли вертикально в три строки — теперь одна строка,
  липкая шапка с мегаменю «Направления» (16 направлений с описаниями из Tilda).
- **Hero.** Правая панель со счётчиками и консультацией была за краем макета
  (на 1440 её не было видно) — теперь она часть сетки и адаптируется.
- **Дублирующийся блок.** На странице дважды шёл «Основные направления поставок»:
  карточки с товарами и фотокарточки отраслей. Второй блок переименован
  в «Отрасли, с которыми работаем» — по смыслу карточек (01–06, ссылки на отраслевые страницы).
- **Новости.** Tilda-лента тянулась с их сервера и падала при переезде домена.
  Теперь это обычные карточки в разметке (4 последние публикации), ссылки пока
  на Tilda-посты. Правится руками в `index.html`.
- **Формы.** Вместо Tilda-форм — своя модалка с маской телефона, валидацией и
  отправкой на `send.php`.
- **Мобильная версия.** Отдельной вёрстки под мобилки в Tilda-экспорте не было —
  сделана адаптивная сетка (3 → 2 → 1 колонка, бургер-меню, модалка на всю ширину).
- **Мелочи.** Убрана чёрная кнопка «Все статьи», которая висела под карточками
  отраслей; добавлены alt-тексты, focus-состояния, `prefers-reduced-motion`.
