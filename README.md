# ESPBS

Стартовая страница проекта: [starosvetsky.github.io/ESPBS](https://starosvetsky.github.io/ESPBS/).

Страница состоит из HTML и CSS. GitHub Actions публикует только файлы страницы из ветки `main`. В репозитории также находится сохранившаяся часть Python/Tkinter-парсера v0.5 и новое независимое ядро хранения `espbs`. Старому GUI по-прежнему не хватает адаптеров и конфигурации; его запуск пока не восстановлен.

## Начало разработки

[План и состояние этапов](docs/PLAN.md) · [Команды ядра и формат архивов](docs/ARCHIVES.md)

Первый шаг: партии в SQLite, сохранение записей по мере поступления, XML внутри ZIP и независимая проверка архива. Python 3.12+, для ядра сторонние зависимости не нужны.

```shell
python -m espbs --help
python -m unittest discover -s tests -v
```

Это работающий слой хранения, пока без реального сбора, нового интерфейса, очистки серверного диска и интеграции с Selectel. Архив содержит товарные данные и ссылки на вложения; сами документы и изображения пока не скачиваются. Тесты используют синтетические данные.

## Desktop-приложение и подключение парсера

[UX Flow и порядок продолжения разработки](docs/UX_FLOW.md) описывают экраны приложения, управление существующим парсером, прогресс, качество данных, синхронизацию и встроенную консоль. В документе отдельно указаны подтверждённые требования и решения, которые нужно проверить после загрузки кода.

Парсер собирает данные на Selectel. По мере заполнения пользователь вручную скачивает партии на компьютер и после проверки архива освобождает место на сервере. Предлагаемый формат — ZIP с XML и связанными файлами; схема XML ещё не зафиксирована. При достижении дискового лимита сбор приостанавливается без удаления невыгруженных данных. Постоянное подключение компьютера не требуется. В будущем сохранённые архивы используются для выгрузки товаров в EnergoStore/OpenCart. Это требования к разработке, пока не реализованные возможности.
