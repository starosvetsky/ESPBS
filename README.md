# ESPBS

Стартовая страница проекта: [starosvetsky.github.io/ESPBS](https://starosvetsky.github.io/ESPBS/).

Страница состоит из HTML и CSS. GitHub Actions публикует только файлы страницы из ветки `main`. В репозитории также находится сохранившаяся часть Python/Tkinter-парсера v0.5 и новое независимое ядро хранения `espbs`. Старому GUI по-прежнему не хватает адаптеров и конфигурации; его запуск пока не восстановлен.

## Начало разработки

[План и состояние этапов](docs/PLAN.md) · [Команды ядра и формат архивов](docs/ARCHIVES.md) · [Сбор Eltex](docs/COLLECTION.md)

Первый шаг: партии в SQLite, сохранение записей по мере поступления, XML внутри ZIP и независимая проверка архива. Python 3.12+, для ядра сторонние зависимости не нужны.

```shell
python -m espbs --help
python -m pip install -r requirements-parser.txt
python -m espbs collect eltex --limit 3
python -m unittest discover -s tests -v
```

Работают хранение, ограниченный сбор Eltex, остановка и продолжение задания. Новый интерфейс, очистка диска и развёртывание на Selectel ещё впереди. Архив содержит товарные данные и ссылки на вложения; сами документы и изображения пока не скачиваются. Unit-тесты используют синтетические данные; отдельно выполнен реальный сбор двух карточек Eltex.

## Desktop-приложение и подключение парсера

[UX Flow и порядок продолжения разработки](docs/UX_FLOW.md) описывают экраны приложения, управление существующим парсером, прогресс, качество данных, синхронизацию и встроенную консоль. В документе отдельно указаны подтверждённые требования и решения, которые нужно проверить после загрузки кода.

По плану парсер собирает данные на Selectel. По мере заполнения пользователь вручную скачивает партии на компьютер и после проверки архива освобождает место на сервере. ZIP/XML v1 уже реализован, вложения пока представлены ссылками. При достижении дискового лимита сбор должен приостанавливаться без удаления невыгруженных данных; эта защита ещё не реализована. Постоянное подключение компьютера не требуется. Будущий импорт в EnergoStore/OpenCart разрабатывается отдельно.
