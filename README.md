# ESPBS

Стартовая страница проекта: [starosvetsky.github.io/ESPBS](https://starosvetsky.github.io/ESPBS/).

Страница состоит из HTML и CSS. GitHub Actions публикует изменения из ветки `main`. В репозитории также находится сохранившаяся часть Python/Tkinter-парсера v0.5; отсутствующие адаптеры и конфигурацию предстоит реализовать.

## Desktop-приложение и подключение парсера

[UX Flow и порядок продолжения разработки](docs/UX_FLOW.md) описывают экраны приложения, управление существующим парсером, прогресс, качество данных, синхронизацию и встроенную консоль. В документе отдельно указаны подтверждённые требования и решения, которые нужно проверить после загрузки кода.

Основная БД и собранные файлы должны храниться на компьютере пользователя. Диск Selectel ограничен: при удалённом сборе предусматривается ограниченный временный буфер с подтверждаемой передачей на компьютер и паузой при заполнении. После развёртывания EnergoStore/OpenCart выбранные товары будут выгружаться с компьютера на сервер магазина. Это требования к разработке, пока не реализованные возможности.
