# ESPBS

Статичная стартовая страница проекта ESPBS. Она подготовлена для GitHub Pages. Исходный код парсера будет подключен после передачи.

## Публикация через GitHub Pages

1. Создайте репозиторий `ESPBS` в нужном аккаунте GitHub.
2. Загрузите файлы проекта в ветку `main`.
3. В настройках репозитория откройте **Pages** и выберите источник **GitHub Actions**.
4. После первого успешного запуска адрес опубликованной страницы появится в разделе Pages.

Сборка не нужна: сайт состоит из HTML и CSS. Данные парсера и его подключение пока не настроены.
